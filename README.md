# Guess the number
A simple number guessing game built with python.

## Description

In this game, the computer randomly selects a number between 1 and 20. The player tries to guess the number and receives hints to guess higher or lower.

## Features

1. Generate a random number between 1 and 20
2. Allow the player to enter guesses
3. Show hints if guess is too high or too low
4. Count the number of attempts
5. Display a winning message when the player guesses correctly

## Technologies

- Python 3
- Random module

## Python concepts Used

- Variables
- User input
- Integers
- If / elif statements
- While loops
- Break statements
- Comparison operators
- F-String
- Random number generation

## How to Run

1. Install python 3
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command: python game.py


## About 

This project was created as a Python practice to learn loops, conditional statements, user input, and random number generation.
